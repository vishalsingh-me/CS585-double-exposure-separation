\section*{Abstract}
Double exposure combines two visual scenes into one image. This project studies the inverse problem: given a single double-exposure RGB image, predict the two original source images that generated it. The task is underdetermined because one observed mixture must explain two full latent images. Real double-exposure photographs rarely provide ground-truth source layers, so this project builds a supervised synthetic framework using Places365 as a clean natural-image source pool. The pipeline samples two images, converts them to RGB, resizes and crops them, creates a controlled double-exposure mixture, and saves the mixture, both sources, and metadata. We evaluated multiple models: Dual-Head U-Net, TwoDecoderUNet, and a Two-Stage Residual Refinement U-Net. All models are trained with permutation-invariant supervision to handle the ambiguity that either output branch may correspond to either source image. The best result came from the Two-Stage Residual Refinement U-Net trained on 2000 synthetic pairs. On a 200-sample validation set, this model achieved L1 0.2507, MSE 0.0280, PSNR 16.25 dB, and SSIM 0.5932. Increasing the data scale significantly improved performance, reducing some instability. However, source leakage and ghosting remain visible, indicating that the task is not fully solved.

\section{Introduction}

Double exposure is a visual composition in which two scenes are blended into one image. In image and video computing, this can be treated as an image formation problem: two latent images are combined by a forward operator to create a single observation. The inverse problem asks whether the original layers can be recovered from the observed mixture.

The task is useful because layer recovery could support image editing, restoration, manipulation of composite imagery, and analysis of layered scenes. It is also challenging because the target is not one corrected image, but two complete source images. In the simplest synthetic setting used in the final experiments, the forward model is
\[
I = \alpha I_1 + (1-\alpha) I_2,
\]
where $I_1$ and $I_2$ are source images, $I$ is the observed mixture, and $\alpha$ is sampled from a configurable range, usually $[0.3,0.7]$. At each pixel and color channel,
\[
I(x,y,c)=\alpha I_1(x,y,c)+(1-\alpha)I_2(x,y,c).
\]
This is one equation with two unknown source values. Even if alpha is known, many source pairs can explain the same observation. The model therefore needs learned natural-image priors.

Real double-exposure images rarely include the two original source layers. This project therefore generates synthetic supervised data from Places365 images. The pipeline is:
\begin{center}
clean sources $\rightarrow$ synthetic blend $\rightarrow$ \\ supervised inverse model $\rightarrow$ predicted sources.
\end{center}
The learned model is
\[
G_\phi(I)=(\hat I_1,\hat I_2).
\]

\textbf{Contributions.} This project makes four main contributions. First, it converts double-exposure separation into a supervised learning problem by building a synthetic Places365-based generation pipeline with full metadata logging. Second, it formulates the task with permutation-invariant supervision to handle the inherent source-order ambiguity. Third, it evaluates three U-Net-style separator architectures: a Dual-Head U-Net, a TwoDecoderUNet, and a Two-Stage Residual Refinement U-Net. Fourth, it demonstrates experimentally that data scale is a primary bottleneck: the Two-Stage model trained on 100 pairs shows weak separation, but the same architecture trained on 2,000 pairs reaches PSNR~16.25\,dB and SSIM~0.5932 while still exhibiting visible ghosting, indicating the task is not fully solved.

\textbf{Scope relative to the original proposal.}
The original proposal included additional directions such as an explicit inverse-model or unrolled-inference variant (referred to as Model~B in the milestone plan). During implementation, the project scope shifted toward completing a reproducible supervised pipeline, establishing U-Net-style baselines, and testing whether data scale and multi-stage refinement improve separation quality. The final implementation therefore focuses on the Dual-Head U-Net, TwoDecoderUNet, and Two-Stage Residual Refinement U-Net. Model~B remains a future extension rather than a completed component.

\section{Related Work}

\subsection{Single-Image Reflection Removal and Layer Separation}
Double-exposure separation is related to image layer separation and single-image reflection removal. Reflection removal also observes a mixture-like image and attempts to separate latent layers. Work such as Guo et al.\ (2014), Yang et al.\ (2018), Li et al.\ (2020), and Wan et al.\ (2023) motivates the difficulty of decomposing one observation into multiple latent images. This project differs because the hidden layers are two double-exposure-style source images rather than necessarily transmission and glass reflection layers. The mathematical structure is nevertheless similar.

\subsection{Synthetic Data for Supervised Inverse Problems}
Many inverse problems lack paired real data. Synthetic data provides a practical way to obtain ground truth. Here, the generator saves $I_1$, $I_2$, and $I$, so supervised losses and quantitative evaluation are possible. Synthetic data also makes the forward process interpretable because alpha, blur, gamma, mask, translation, noise, and labels can be recorded for each pair. The limitation is that synthetic mixtures may not fully match real double-exposure photographs.

\subsection{U-Net and Image-to-Image Prediction}
U-Net (Ronneberger et al., 2015) is a standard encoder-decoder architecture for dense prediction. It combines downsampling for context with upsampling and skip connections for spatial detail. The Dual-Head U-Net baseline adapts this idea by predicting six output channels: three for one source and three for the other. This is a natural first baseline, but it must allocate visual content across two output images rather than produce one restored image.

\subsection{Source Image Pool}
The project uses Places365 as a pool of clean natural images. Places365 is not a native double-exposure dataset. Each image is treated as a candidate latent layer. This choice is practical because the generator can sample two clean images, blend them, and retain the originals as supervision targets.

\subsection{Synthetic Double-Exposure Generation}
For each synthetic pair, the generator samples two images, loads them as RGB, center-crops and resizes them, optionally translates and blurs the second source, blends the two sources, optionally applies gamma correction or noise, and saves the mixture and source targets. The general forward process is
\[
I=f_\theta(I_1,I_2)+\epsilon,
\]
where $\theta$ represents synthesis parameters and $\epsilon$ represents noise. For mask blending,
\[
I(x,y)=M(x,y)I_1(x,y)+(1-M(x,y))I_2(x,y).
\]
The current final experiments use the simplest \texttt{linear\_clean} mode.

\subsection{Metadata, Saved Structure, and Metrics}
Each row of \texttt{pair\_manifest.csv} records fields such as pair id, split, synthesis mode, source paths, labels, same-label flag, mixture path, target paths, image size, alpha, gamma, noise standard deviation, blur radius, translation, mask type, and seed. This metadata supports grouped evaluation by alpha bin, synthesis mode, and same-label flag.

The saved dataset stores \texttt{mixtures/}, \texttt{source\_1/}, \texttt{source\_2/}, and \texttt{pair\_manifest.csv}. The loader reads images from disk, converts them to tensors, optionally resizes them, and preserves metadata. Evaluation reports permutation-matched L1, MSE when available, PSNR, SSIM, qualitative grids, and error maps.

Earlier experiments used only 100 train pairs and 20 validation pairs. Later, a larger synthetic dataset was generated from Places365 using 2000 train pairs and 200 validation pairs. This larger dataset was used to test whether poor performance was mainly caused by limited data scale. For the final large-data experiment, we extracted a Places365 source pool containing 382,246 images on SCC. From this pool, we created source-image split CSVs with 5,000 training candidates and 1,000 validation candidates, then generated 2,000 training mixtures and 200 validation mixtures.

\section{Method}

\begin{figure}[t]
\centering
\includegraphics[width=\linewidth]{figures/fig2_supervised.png}
\caption{Supervised inverse learning: the model receives only the mixture and is trained against the two source targets.}
\label{fig:supervised}
\end{figure}

\subsection{Supervised Inverse Learning}
The model receives only the blended image as input and predicts two source layers:
\[
G_\phi(I)=(\hat I_1,\hat I_2).
\]
The original sources are used as training targets, not as inference inputs.

\subsection{Permutation-Invariant Loss}
Output order is ambiguous. The project therefore uses permutation-invariant L1 loss:
\[
L_A=L_1(\hat I_1,I_1)+L_1(\hat I_2,I_2),
\]
\[
L_B=L_1(\hat I_1,I_2)+L_1(\hat I_2,I_1),
\]
\[
L_{PIT}=\min(L_A,L_B).
\]
The selected assignment is also used for visualization.

\subsection{Dual-Head U-Net Baseline}
The Dual-Head U-Net maps a three-channel mixture to a six-channel output,
\[
Y=G_\phi(I), \quad Y\in \mathbb{R}^{6\times H\times W},
\]
then splits channels:
\[
\hat I_1=Y[0:3,:,:], \quad \hat I_2=Y[3:6,:,:].
\]
Most computation is shared, and the model separates into two outputs only at the final layer.

\subsection{TwoDecoderUNet Extension}
TwoDecoderUNet uses a shared encoder and two independent decoders:
\begin{align*}
\text{mixture} &\rightarrow \text{shared encoder} \rightarrow \text{bottleneck} \\
&\rightarrow
\begin{cases}
\text{decoder 1}\rightarrow\hat I_1\\
\text{decoder 2}\rightarrow\hat I_2
\end{cases}
\end{align*}
The hypothesis is that separate decoders may allow branch specialization. The current results show that this architectural change alone is not sufficient at the current data scale.

\subsection{Two-Stage Residual Refinement U-Net}
The Two-Stage Residual Refinement U-Net was added to directly target ghosting and source leakage. Stage 1 produces coarse separated outputs using a shared encoder and two decoder branches. Stage 2 receives a 9-channel tensor formed by concatenating the original mixture, coarse prediction 1, and coarse prediction 2. It predicts a 6-channel residual correction, where the first three channels refine source 1 and the last three channels refine source 2. The final outputs are coarse predictions plus residual corrections, clamped to the valid image range. This model is inspired by multi-stage image restoration: first estimate rough layers, then refine them using the mixture and both coarse outputs. The architecture can be summarized as:
\[
I \rightarrow (\hat I^{c}_1, \hat I^{c}_2)
\]
\[
[I, \hat I^{c}_1, \hat I^{c}_2] \rightarrow (\Delta I_1, \Delta I_2)
\]
\[
\hat I_1 = \mathrm{clip}(\hat I^{c}_1 + \Delta I_1), \quad
\hat I_2 = \mathrm{clip}(\hat I^{c}_2 + \Delta I_2)
\]
Here, $\hat I^{c}_1$ and $\hat I^{c}_2$ are coarse predictions from the first stage, and $\Delta I_1,\Delta I_2$ are residual corrections predicted by the refinement stage. The refinement stage receives the 9-channel concatenation of the mixture and both coarse outputs. The final large-data refinement run used PIT-only loss so it is directly comparable to previous PIT-only baselines.

\subsection{Auxiliary Losses}
Reconstruction consistency is
\[
\hat I_{mix}=\alpha \hat I_1+(1-\alpha)\hat I_2,\quad
L_{recon}=L_1(\hat I_{mix},I).
\]
Output decorrelation flattens, mean-centers, normalizes, and compares the two predictions with absolute cosine similarity. The auxiliary-loss experiment uses
\[
L_{total}=L_{PIT}+\lambda_{recon}L_{recon}+\lambda_{corr}L_{corr},
\]
with $\lambda_{recon}=0.1$ and $\lambda_{corr}=0.01$. Reconstruction is physically meaningful, but it can still permit mixture-like outputs if not combined with strong disentanglement priors.

\subsection{Visualization Protocol}
Evaluation grids display Original Source 1, Original Source 2, Blended Mixture, Predicted Source 1, Predicted Source 2, Error 1, and Error 2. Predictions are permutation-matched, and error maps are scaled by 3.0 and clamped to $[0,1]$.

\subsection{Pipeline and Smoke-Test Validation}
The dataset diagnostic verifies image loading, tensor shape, and value ranges. The smoke test initializes a model, runs a forward pass, computes PIT, reconstruction, and correlation losses, performs one optimizer step, and saves a visualization. SCC GPU training completed for both TwoDecoderUNet variants, and scripts saved logs, checkpoints, metrics, grouped CSVs, and visual grids.

\subsection{Dual-Head U-Net Baseline}
The strongest numerical baseline is \texttt{experiments/baseline\_unet\_100ep}. Training loss decreased from 0.4278 at epoch 1 to 0.1464 at epoch 100. Validation loss reached its best value of 0.2513 at epoch 33, then worsened to 0.3126 at epoch 100. The model produces two outputs, but qualitative grids show source leakage.

\subsection{TwoDecoderUNet Experiments}
With reconstruction and decorrelation, training total loss decreased from 0.4454 to 0.2199 over 30 epochs. Validation total loss reached its best value at epoch 21 and worsened by epoch 30. Evaluation gives L1 0.2789, MSE 0.0330, PSNR 15.18 dB, and SSIM 0.5003.

The PIT-only TwoDecoderUNet decreased training loss from 0.4258 to 0.2128. Validation again improved early, reached its best value at epoch 21, and worsened by epoch 30. Evaluation gives L1 0.2765, MSE 0.0327, PSNR 15.22 dB, and SSIM 0.5109. PIT-only slightly outperformed the auxiliary-loss variant, but neither TwoDecoderUNet run improved over the best Dual-Head baseline.

\subsection{Large-Data Refinement Experiment}
The strongest final experiment used the Two-Stage Residual Refinement U-Net trained on 2,000 synthetic training pairs and evaluated on 200 validation pairs. It achieved L1 0.2507, MSE 0.0280, PSNR 16.25 dB, and SSIM 0.5932. Compared with the small-data Two-Stage model, this improves L1 from 0.2755 to 0.2507, PSNR from 15.03 dB to 16.25 dB, and SSIM from 0.5133 to 0.5932. This shows that data scale was a major bottleneck in the earlier experiments.

The large-data Two-Stage model achieved the best PSNR and SSIM and the lowest reported MSE among our experiments, while slightly improving L1 over the small-data Dual-Head baseline. Since the validation set size differs across experiments, this result should be interpreted as the strongest final experiment rather than a perfectly controlled architecture-only comparison.

Table~\ref{tab:alpha_bins} shows performance grouped by alpha range. Separation quality degrades as alpha approaches 0.5, with the lowest-alpha bin (0.30--0.40) achieving PSNR 16.58 dB and SSIM 0.6016 versus PSNR 16.07 dB and SSIM 0.5833 for the highest bin (0.60--0.70). This is consistent with the mixture becoming more ambiguous when neither source dominates: at extreme alpha values one source contributes more signal, making it easier to identify; near 0.5 both sources contribute equally and the decomposition is harder.

\subsection{Qualitative Analysis}
The large-data model produces more stable predictions than the small-data models. Predicted sources still show visible ghosting and source leakage. Error maps highlight regions where both source images contain overlapping structure. The improvement is measurable in PSNR/SSIM, but the task remains unsolved.

\section{Discussion}

\subsection{Why the Task Is Ill-Posed}
For each pixel and channel, there is one observed value and two unknown source values. Spatial context helps, but many decompositions are still plausible. The model must learn a natural-image prior strong enough to decide which structures belong in which layer.

\subsection{Model Capacity and Data Scale}
The large-data experiment changes the interpretation of the project. With only 100 training pairs, stronger architectures did not meaningfully improve over the baseline and still produced ghosted outputs. After increasing the dataset to 2000 synthetic pairs, the Two-Stage Residual Refinement model achieved the best PSNR and SSIM among all experiments. This suggests that double-exposure separation requires both architectural capacity and sufficient synthetic diversity. Model architecture alone did not fix the problem in the small-data setting, as the Two-Stage model only became competitive after increasing data scale.

\subsection{Interpretability Through Metadata}
The metadata design records alpha, synthesis mode, blur radius, translation, gamma, and source-label relationship for every generated pair. Alpha-bin results are reported in Table~\ref{tab:alpha_bins} for the large-data experiment across 200 validation samples. This infrastructure supports further grouped analysis by synthesis mode and source-label relationship in future larger-scale studies.

\subsection{What We Honestly Do Not Claim}
We do not claim clean recovery of both source images. The large-data experiment reduces but does not eliminate ghosting. We do not claim the problem is solved, nor do we claim that the model generalizes to real double-exposure photos. We do claim that the pipeline works end-to-end, multiple architectures were evaluated, and the Two-Stage Residual Refinement U-Net trained on larger synthetic data achieved the best final metrics. Increasing data scale significantly improved PSNR and SSIM, but source leakage and ghosting remain visible, so separation is still incomplete.

\subsection{Future Direction: Stronger Priors}
The current results motivate stronger restoration backbones. U-Net-style models trained from scratch have limited natural-image priors, especially on small datasets. Future work should scale synthetic training data further, compare against a copy-mixture lower bound, and evaluate pretrained CNN encoders or transformer-based restoration architectures such as SwinIR, Restormer, Uformer, NAFNet, or MPRNet-style multi-stage designs. None of these models are implemented in this report. They are motivated by the remaining ghosting and source leakage observed in the final qualitative results. Additional future directions include perceptual and SSIM-based losses, harder synthesis regimes beyond \texttt{linear\_clean}, and generalization evaluation on real double-exposure photographs.

\section{Conclusion}
This project built and evaluated a supervised framework for separating synthetic double-exposure images into two predicted source layers. The central finding is not that the task is solved, but that the experiments identify the key bottlenecks. On small data (100 training pairs), increasing architectural complexity from a Dual-Head U-Net to a TwoDecoderUNet or Two-Stage Refinement model did not eliminate ghosting or source leakage. After scaling to 2,000 synthetic training pairs, the Two-Stage Residual Refinement U-Net achieved the strongest metrics: L1~0.2507, MSE~0.0280, PSNR~16.25\,dB, and SSIM~0.5932 on 200 validation samples. This demonstrates that synthetic data diversity is a critical factor for learning useful separation priors. However, qualitative results still contain visible ghosting, so clean double-exposure decomposition remains an open problem. Future work should combine larger synthetic datasets with pretrained restoration backbones, perceptual training objectives, and evaluation on real double-exposure photographs.
